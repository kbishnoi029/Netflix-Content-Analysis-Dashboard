🎬 Netflix Content Analysis Dashboard

 📌 Project Overview

This project is an interactive Netflix Content Analysis Dashboard built using Microsoft Excel.

The dashboard analyzes over **8,800 Netflix titles** and provides interactive insights into content trends using Pivot Tables, Pivot Charts, Power Query, KPI Cards, and Slicers.

---

🛠 Tools Used

- Microsoft Excel
- Power Query
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Dashboard Design

---

📊 Dashboard Features

- Total Titles KPI
- Movies vs TV Shows
- Rating Distribution
- Content by Release Year
- Top 10 Countries
- Top Genres
- Interactive Filters (Slicers)

📈 Key Insights

- Movies make up the majority of Netflix's content.
- TV Shows represent a smaller but significant portion.
- Content additions increased rapidly after 2015.
- The United States has the highest number of titles.
- TV-MA is the most common content rating.
